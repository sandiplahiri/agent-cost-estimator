# Security reporting

Please report suspected vulnerabilities privately through [GitHub's Report a vulnerability form](https://github.com/sandiplahiri/agent-cost-estimator/security/advisories). Do not open a public issue or pull request with exploit details. If the button is unavailable, open a public issue asking for a private reporting channel without including vulnerability details.

Include the affected version or commit, impact, and reproducible steps using synthetic data. Do not send customer estimates, workbooks, prompts, credentials, or other private information. Please avoid accessing data that is not yours, disrupting other users, or publicly disclosing the issue while it is being assessed.

Maintainers will triage reports in the private advisory, ask for details if needed, and coordinate a fix and disclosure there. There is no guaranteed response or resolution time.

Ordinary bugs and feature requests belong in [public GitHub Issues](https://github.com/sandiplahiri/agent-cost-estimator/issues/new/choose) with sanitized examples.
